## 🤖 Features

 - 一张设计图可以包含所有应用场景和服务
 - 一个流程对应前端的一个功能，功能可视化，所见即所得
 - 允许边生成代码边执行，能够将用户意图变成行动
 - 支持动态规划任务的能力，能做到边思考边执行

## 🚀 Getting Started

执行以下步骤来启动服务：

```commandline
git clone https://github.com/DeepSophos/OneNode.git
pip install -r backend/requirements.txt
bash backend/start.sh
```
